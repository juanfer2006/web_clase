Resumen: etiquetas, atributos y CSS

Etiquetas usadas

  • html: raíz del documento HTML.
  • head, meta, title: metadatos y título.
  • link: incluye la hoja de estilos.
  • body: contenido visible de la página.
  • header, main, section, article: elementos semánticos para estructura.
  • h1..h3, p, ul, li: encabezados, párrafos y listas.
  • img: imágenes (foto de perfil).
  • a: enlaces (redes sociales, mailto).
  • strong, em: enfatizar texto (negrita y cursiva).

Atributos usados

  • src (img): ruta de la imagen.
  • alt (img): texto alternativo para accesibilidad.
  • href (a, link): URL destino del enlace.
  • target (a): donde abrir el enlace; _blank abre en nueva pestaña.
  • rel (opcional para enlaces externos, ej. rel="noopener noreferrer").
  • class / id: identificadores para CSS/JS.

CSS (definiciones breves)

  • selector: selecciona elementos HTML para aplicar reglas.
  • propiedad: valor: define apariencia, p. ej. color: #333;.
  • Box model: margen, borde, relleno y contenido influyen en el tamaño.
  • Flexbox: layout flexible para alinear y distribuir elementos.
  • Media queries: reglas que se aplican según el tamaño de pantalla.

Análisis del CSS aplicado

El CSS de esta carpeta (ia/style.css) está pensado para ser simple y educativo:

  • Usa un contenedor central con max-width para lectura cómoda.
  • La cabecera utiliza display: flex para alinear la foto y la información.
  • Las tarjetas tienen sombras ligeras y padding para separar visualmente secciones.
  • Incluye una media query para pantallas pequeñas que apila la cabecera verticalmente.

Conclusión: el CSS es limpio, accesible y fácil de expandir. Para mejorar, se puede añadir variables CSS, un sistema de colores y mejor soporte para impresión.

Instrucciones para subir a producción (GitHub Pages)

  1. Inicializa un repositorio Git en la carpeta del proyecto si no existe.
  2. Agrega, commitea y sube al repositorio remoto en GitHub.
  3. En la configuración del repositorio en GitHub, activa GitHub Pages desde la rama main o gh-pages y selecciona la carpeta raíz o la carpeta donde está el CV.
  4. La página estará disponible en la URL indicada por GitHub Pages.
